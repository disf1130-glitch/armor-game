# Сайт Armor Game на Cloudflare — таймер 30 мин + чат + онлайн

Папка `cloudflare-site` — готовый сайт для Cloudflare Pages.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | Лендинг: таймер 30:00 до выхода, чат, бейдж онлайна |
| `functions/api/chat.js` | Общий чат (GET/POST) |
| `functions/api/online.js` | Счётчик онлайна (heartbeat каждые 15 сек) |
| `functions/api/release.js` | Общий дедлайн таймера для всех посетителей |

## Деплой за 5 минут (бесплатно)

1. Зайди на https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Upload assets** (или подключи GitHub-репозиторий с этой папкой).
2. Перетащи содержимое папки `cloudflare-site`.
3. Получишь адрес вида `armor-game.pages.dev` — готово, сайт уже работает
   (чат и онлайн в демо-режиме: чат общий в пределах изолята, онлайн примерный).

### Привязка KV: общий чат и честный онлайн (1 минута)
1. В дашборде: **Workers & Pages** → твой проект → **Settings** → **Bindings** → **Add** → **KV namespace** → создай `agkv`.
2. Привяжи его с именем переменной **`AGKV`** к **Production** окружению.
3. Сделай **Retry deployment** — всё, чат общий и переживает рестарт,
   онлайн считается по heartbeat-ключам с TTL 40 сек.

## Как это работает
- **Таймер**: первый визит стартует дедлайн «сейчас + 30 мин», он хранится в KV
  (`release_deadline`), поэтому у всех посетителей цифры одинаковые.
  Без KV каждый браузер считает локально (тоже 30:00 с первого открытия).
- **Чат**: последние 100 сообщений в KV-ключе `chat`, фронт опрашивает каждые 3 сек.
- **Онлайн**: фронт шлёт heartbeat каждые 15 сек, сервер считает ключи `online:*`
  (живут 40 сек). Без KV — in-memory счётчик.
